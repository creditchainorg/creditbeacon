# CreditChain Network Configs

This directory is reserved for canonical CreditChain Beacon network
configuration.

Current subdirectories are placeholders:

- `local`
- `devnet`
- `testnet`
- `mainnet`

Do not copy Ethereum mainnet, testnet, fork version, genesis, ENR, bootnode, or
deposit-contract values here as CreditChain defaults. Values must come from the
CreditChain canonical network specification.
